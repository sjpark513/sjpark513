# Hi, I'm Sungjin Park

**Test systems engineer moving into manufacturing AI.**
I have built the electrical, embedded and software side of automotive test rigs, and I am now building LLM agents that help engineers diagnose problems on the shop floor.

### Background

- **Hardware & embedded**: circuit and PCB design, FPGA development, firmware
- **Automotive test systems** at Mando, a Korean Tier-1 supplier: electrical/electronic design and control software for performance, durability, quality and end-of-line test equipment
- **Industrial operations** in Germany: equipment consulting and plant management

### Now building

**[test-rig-anomaly-agent](https://github.com/sjpark513/test-rig-anomaly-agent)**: an LLM agent that reads test rig sensor data, searches test procedures and failure history, and drafts an inspection report.
Built in public over six phases (Oct 2026 – Apr 2027): structured extraction → RAG → tool-using agent with a Modbus rig simulator → evaluation → deployment.

### Tech

**Engineering:** `Circuit design` · `PCB design` · `FPGA` · `Embedded firmware` · `Test rig control` · `CAN` · `CANoe`

**AI (learning in public):** `Python` · `LLM APIs` · `RAG` · `AI agents` · `Modbus`
